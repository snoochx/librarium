# 📚 Librarium

**Librarium** — веб-приложение для управления книжным каталогом, личной библиотекой и взаимодействия пользователей с администраторами.

Проект разработан на **Java / Spring Boot** и позволяет пользователям искать книги, формировать собственную коллекцию, публиковать отзывы и оценки, а также предлагать новые книги для добавления в каталог. Для администраторов реализована полноценная панель управления книгами и пользовательскими предложениями.

## ✨ Основные возможности пользователя
- Просмотр каталога книг
- Поиск книг по названию
- Сортировка каталога
- Просмотр рейтингов
- Добавление отзывов
- Добавление книг в личную коллекцию
- Предложение новых книг администраторам

## 🚀 Запуск проекта

### Требования

- Java 21
- Maven
- Git

### Клонирование проекта

```bash
git clone https://github.com/snoochx/librarium.git
cd librarium
```

### Запуск

```bash
mvn spring-boot:run
```

После запуска приложение будет доступно по адресу

```
http://localhost:8080
```

Если используется профиль разработки, также доступна консоль H2 Database.

## 📋 Основные функции

### Каталог книг

| Функция | Описание |
|----------|----------|
| Просмотр каталога | Отображение всех доступных книг |
| Поиск | По названию книги |
| Сортировка | Несколько вариантов отображения |
| Карточка книги | Подробная информация, рейтинг и отзывы |

### Личная библиотека

| Функция | Описание |
|----------|----------|
| Добавление книги | Сохранение книги в личную коллекцию |
| Статусы | Не читал, В планах, Прочитано |
| Просмотр коллекции | Все книги пользователя по статусам |

### Отзывы

| Функция | Описание |
|----------|----------|
| Добавление | Пользователь может оставить отзыв |
| Изменение | Автор может изменить свой отзыв |
| Просмотр | Все отзывы отображаются в карточке книги |

### Администрирование

| Функция | Описание |
|----------|----------|
| Добавление книги | Создание новой записи |
| Редактирование | Изменение информации о книге |
| Удаление | Удаление книги из каталога |
| Предложения | Просмотр заявок пользователей |
| Модерация | Одобрение или отклонение предложений |

## 🔐 Авторизация

Для входа используется **Firebase Authentication** с авторизацией через Google.

После успешной авторизации:

- создаётся пользовательский профиль;
- восстанавливается пользовательская сессия;
- назначается роль пользователя;
- становятся доступны персональные функции приложения.

## 🗄 Используемые базы данных

Во время разработки используется **H2 Database**, а для развёртывания может использоваться **PostgreSQL**.

Основные сущности системы:

- Book
- BookReview
- BookSuggestion
- UserProfile
- UserBookEntry
